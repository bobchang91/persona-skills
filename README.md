# 人物思维 skill（Claude Code）

用[女娲 nuwa-skill](https://github.com/alchaincyf/nuwa-skill) 把一个人的思维方式蒸馏成 skill，内容来自公开的演讲、访谈、文章。

| skill | 是谁 |
|---|---|
| `persona-munger` | 查理·芒格：心智模型、决策启发式 |
| `persona-trump` | 唐纳德·特朗普：谈判、表达、决策方式 |

## 怎么装
把整个资料夹（例如 `persona-munger/`）放进自己电脑的 `~/.claude/skills/`，开新的 Claude Code 对话就能用。

## 怎么用
- 点名才用：「用芒格思维想想……」「特朗普会怎么谈这件事」
- 一般问题不会自动变成那个人；用到时回答里会标「🧠 这段用了 XX 的思维」
- 想一直用：说「继续用芒格」；停：说「退出」
